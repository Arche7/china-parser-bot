# China Parser Bot 🇨🇳

Telegram-бот, который следит за брендами на китайских площадках и присылает
**новые объявления**, как только они появляются.

| Площадка | Статус | Как получаем данные |
|---|---|---|
| Goofish (闲鱼 / Xianyu) | ✅ работает | платный актор на Apify |
| 95分 | ⏳ заготовка | готового API нет — план в `sources/fen95.py` |

## Что умеет

- Добавить бренд: `/add stone island` или кнопкой «➕ Добавить бренд»
- Фильтр по цене в юанях: `/add arcteryx 500-3000`, `/add rick owens -2000`
- Китайские названия: для известных брендов бот сам предлагает добавить
  иероглифы (`arcteryx` → `始祖鸟`). Список — в `brands_cn.py`, его можно дополнять
- Одно и то же объявление дважды не приходит, даже если нашлось по двум названиям
- Список брендов с кнопками удаления: `/list`
- Пауза/продолжение уведомлений: `/pause`, `/resume`
- Сообщение с фото, ценой в ¥ и примерно в ₽, городом, продавцом и кнопкой «Открыть»
- Доступ по подписке: админ выдаёт доступ командой `/grant <id> <дни>`
- `/stats` — статистика и примерный расход денег на Apify

## Структура проекта

```
bot.py            — запуск бота
config.py         — настройки из переменных окружения
db.py             — база данных SQLite
handlers.py       — команды и кнопки Telegram
monitor.py        — проверка новых объявлений и рассылка
brands_cn.py      — китайские названия брендов
sources/
  base.py         — общий шаблон площадки
  goofish.py      — Goofish через Apify
  fen95.py        — 95分 (заготовка, выключена)
requirements.txt  — библиотеки Python
railway.json      — как Railway собирает и запускает бота
.python-version   — версия Python для Railway
.env.example      — пример файла с токенами
```

## Сколько объявлений и сколько денег

За одну проверку бот берёт `MAX_ITEMS` самых свежих объявлений по каждому
бренду (по умолчанию 10) и присылает только те, которых ещё не было.
Проверок в сутки при интервале 30 минут — 48. Значит, по одному бренду
бот пришлёт **не больше 480 объявлений в сутки**. На деле приходит столько,
сколько реально выложили новых: по редкому бренду — несколько в день,
по популярному — десятки и сотни.

Если по бренду за 30 минут появляется больше 10 новых объявлений, часть
пропустится. Для популярных брендов увеличь `MAX_ITEMS` (например, до 20)
или уменьши `CHECK_INTERVAL_MIN` (например, до 15) — но это дороже.

Apify берёт ~**$1.6 за 1000 полученных объявлений** (режим summary), причём
платишь за все полученные, а не только за новые. При настройках по умолчанию
один бренд — это 480 объявлений в день, то есть примерно **$0.8 в день**
(~$23 в месяц). Китайское название — это ещё один такой же бренд.
Если 5 человек следят за одним брендом, запрос всё равно один.

## Шаг 1. Токен бота

1. В Telegram открой **@BotFather** → `/newbot`.
2. Придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `1234567890:AAH...` — это `BOT_TOKEN`.

## Шаг 2. Токен Apify

1. Зарегистрируйся на https://apify.com.
2. В консоли: **Settings → API & Integrations** → скопируй **Personal API token** —
   это `APIFY_TOKEN`.
3. В **Billing** поставь лимит расходов.

## Шаг 3. Запуск на Mac (для проверки)

```bash
python3 -m venv .venv            # виртуальное окружение (один раз)
source .venv/bin/activate        # включаем его (в каждом новом терминале)
pip install -r requirements.txt  # ставим библиотеки
cp .env.example .env             # создаём файл настроек
python bot.py
```

В `.env` впиши `BOT_TOKEN`, `APIFY_TOKEN` и свой ID в `ADMIN_IDS`
(ID пришлёт бот по команде `/id`).

## Шаг 4. Деплой на Railway (чтобы работал 24/7)

1. Останови бота на Mac (`Ctrl+C`). С одним токеном Telegram не даёт
   работать двум копиям бота одновременно.
2. На https://railway.com → **New Project** → **Deploy from GitHub repo** →
   выбери `china-parser-bot`. Railway сам найдёт `railway.json` и запустит
   `python bot.py`.
3. Открой сервис → вкладка **Variables** → **New Variable** и добавь:
   `BOT_TOKEN`, `APIFY_TOKEN`, `ADMIN_IDS`
   (по желанию — остальные из `.env.example`).
4. **Том для базы данных** (обязательно, иначе после каждого деплоя бот
   забудет бренды и пользователей): на схеме проекта нажми правой кнопкой
   (или `⌘K`) → **Create Volume** → выбери сервис бота → **Mount path:** `/data`.
   Бот сам найдёт том и положит туда `bot.db`.
5. Сервис перезапустится. Во вкладке **Deployments → View logs** должно
   появиться `Бот @... запущен` и `База данных: /data/bot.db`.

Порт и домен боту не нужны — он сам ходит в Telegram.

## Как продавать доступ

Человек пишет боту `/start`, получает свой ID и присылает тебе.
После оплаты ты пишешь боту `/grant 123456789 30` — доступ на 30 дней
(повторный `/grant` продлевает). `/users` — список, `/revoke id` — закрыть доступ.
Позже сюда можно добавить автоматическую оплату через Telegram Stars.
