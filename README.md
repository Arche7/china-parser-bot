# China Parser Bot 🇨🇳

Telegram-бот, который следит за брендами на китайских площадках и присылает
**новые объявления**, как только они появляются.

| Площадка | Статус | Как получаем данные |
|---|---|---|
| Goofish (闲鱼 / Xianyu) | ✅ работает | платный актор на Apify |
| 95分 | ⏳ заготовка | нет открытого способа — см. `sources/fen95.py` |

## Что умеет

- Добавить бренд: `/add stone island` или кнопкой «➕ Добавить бренд»
- Фильтр по цене в юанях: `/add arcteryx 500-3000`, `/add rick owens -2000`
- Список брендов с кнопками удаления: `/list`
- Пауза/продолжение уведомлений: `/pause`, `/resume`
- Сообщение с фото, ценой в ¥ и примерно в ₽, городом, продавцом и кнопкой «Открыть»
- Доступ по подписке: админ выдаёт доступ командой `/grant <id> <дни>`
- `/stats` — статистика и примерный расход денег на Apify

## Структура проекта

```
bot.py            — запуск бота
config.py         — настройки из переменных окружения
db.py             — база данных SQLite
handlers.py       — команды и кнопки Telegram
monitor.py        — проверка новых объявлений и рассылка
sources/
  base.py         — общий шаблон площадки
  goofish.py      — Goofish через Apify
  fen95.py        — 95分 (заготовка, выключена)
requirements.txt  — библиотеки Python
amvera.yml        — настройки деплоя на Amvera
.env.example      — пример файла с токенами
```

## Сколько это стоит

Apify берёт ~**$1.6 за 1000 объявлений** (режим summary) + небольшую плату за
каждый запуск актора. При настройках по умолчанию (проверка раз в 30 минут,
10 объявлений за раз) один бренд — это 48 запросов × 10 = 480 объявлений в день,
то есть примерно **$0.8 в день за бренд** (~$23 в месяц).

Если 5 человек следят за одним брендом — запрос всё равно один.

Как экономить: увеличь `CHECK_INTERVAL_MIN` (например, 60) или уменьши
`MAX_ITEMS` (например, 5). У нового аккаунта Apify есть бесплатные $5 в месяц —
хватит, чтобы всё проверить.

## Шаг 1. Токен бота

1. В Telegram открой **@BotFather** → `/newbot`.
2. Придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `1234567890:AAH...` — это `BOT_TOKEN`.

## Шаг 2. Токен Apify

1. Зарегистрируйся на https://apify.com (можно через Google/GitHub).
2. Открой страницу актора https://apify.com/unitbytes/goofish-xianyu-search-scraper
   и проверь цену.
3. В консоли: **Settings → API & Integrations** → скопируй **Personal API token** —
   это `APIFY_TOKEN`.
4. В **Billing** можно поставить лимит расходов, чтобы случайно не потратить много.

## Шаг 3. Запуск на Mac (для проверки)

В терминале VS Code, в папке проекта:

```bash
python3 -m venv .venv            # создаём виртуальное окружение (один раз)
source .venv/bin/activate        # включаем его (каждый раз при новом терминале)
pip install -r requirements.txt  # ставим библиотеки
cp .env.example .env             # создаём файл настроек
```

Открой `.env` в VS Code и впиши `BOT_TOKEN` и `APIFY_TOKEN`. Затем:

```bash
python bot.py
```

Напиши боту `/id` — он пришлёт твой ID. Впиши его в `.env` в `ADMIN_IDS`,
останови бота (`Ctrl+C`) и запусти снова. Теперь `/start` → «➕ Добавить бренд».

## Шаг 4. Деплой на Amvera (чтобы работал 24/7)

1. Залей проект на GitHub (файл `.env` не попадёт туда — он в `.gitignore`).
2. На https://amvera.ru → «Создать проект» → тип «Приложение» →
   подключи GitHub-репозиторий (или загрузи файлы вручную).
3. Файл `amvera.yml` уже лежит в проекте — Amvera сама поймёт, как запускать.
4. В проекте открой **«Переменные»** и добавь как **секреты**:
   `BOT_TOKEN`, `APIFY_TOKEN`, `ADMIN_IDS` (и при желании остальные из `.env.example`).
5. Нажми «Собрать» / «Перезапустить». В «Логах» должно появиться
   `Бот @... запущен`.

⚠️ Не запускай бота одновременно на Mac и на Amvera с одним токеном —
Telegram будет ругаться на конфликт. Останови локальный (`Ctrl+C`).

База данных на Amvera хранится в `/data/bot.db` и не теряется при пересборке.

## Как продавать доступ

Пока вручную: человек пишет боту `/start`, получает свой ID и присылает тебе.
После оплаты ты пишешь боту `/grant 123456789 30` — доступ на 30 дней
(повторный `/grant` продлевает). `/users` — список, `/revoke id` — закрыть доступ.
Позже сюда можно добавить автоматическую оплату через Telegram Stars.
